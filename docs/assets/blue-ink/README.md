# Blue-ink illustrations

18 localized figures, six each in Chinese, English and Japanese, were redrawn using the built-in ImageGen tool and the blue-ink-paper-diagram workflow on 2026-10-24.

The final visual contract is black pen doodles, blue handwritten labels and arrows, sparse yellow accents, and a warm-white background filling the canvas. There is **no desk, dark outer frame, visible sheet edge, curled corner, or photographic cast shadow**. The same default has been added to the maintained [blue-ink Skill](https://github.com/EasonZhu1997/Eason-Agent-Skills/tree/main/skills/blue-ink-paper-diagram).

Each guide shows the generated PNG first and keeps editable Mermaid source in a collapsed block. The illustration simplifies labels; implementation requirements remain in the accompanying text and Skill references.

[generation.json](generation.json) records selected paths, dimensions, byte sizes, SHA-256, prompts and review scope. Initial prompts, when included, are historical and superseded by final user corrections and selected images. Some final prompts edit private intermediate generations; this is an audit record, not a guarantee of pixel-identical regeneration. The private historical style reference is not redistributed, and its subject matter was not reused.

Rokid and EverMind logos are original separate assets outside these illustrations. Their rights and provenance are documented in [brand notes](../brand/README.md).
