# Showcase concepts

These three original illustrations explain the repository's developer routes and possible sports-app memory workflows. They are **concept illustrations**, not screenshots, service receipts, product releases or evidence of a deployed Sport Master integration.

| Figure | Purpose |
| --- | --- |
| `glasses-memory-hero-v1.png` | README hero: AIUI JS SDK and Rokid SDK development Skill, with running, cycling and indoor-rowing case imagery |
| `developer-journey-v1.png` | Choose one runtime/service route, configure identity and service, run local checks, then validate the actual service and glasses |
| `memory-loop-concept-v1.png` | Reuse relevant context, recall only when needed, offer contextual coaching, save with permission and separately verify later recall |

All were generated with built-in ImageGen using the blue-ink-paper-diagram style: black pen, blue handwritten labels, sparse yellow accents, and flat full-bleed warm-white paper. There is no desk, dark outer border, visible sheet edge or photographic cast shadow. The hero was corrected to use an indoor rowing machine rather than a water-paddling icon, matching the public case scope.

The actual Sport Master, FUN PIZZA, Rokid and EverMind logos are separate original brand assets. They were not redrawn or embedded by the image generator. See [brand provenance](../brand/README.md).

[generation.json](generation.json) records selected files, prompts, dimensions, SHA-256 values and review scope. The output is not promised to be exclusive or exactly reproducible. The 24 localized technical diagrams are maintained in [blue-ink](../blue-ink/README.md), with their own semantic sources and generation records.
